Before recording: run the reset, delete old drafts in make.com, Chrome window about 1440 wide, zoom 100 percent, close other tabs, notifications off, make.com signed in on the recording laptop, the make.com scenario list open in a second tab, DEFENCE.md and the Galtea dashboard open in two more tabs.

## Honesty checks before you say it on the recording
- Clip 3: only say "that approval runs through make.com" because it does (the split approval scenario).
- Clip 5: do NOT say submit runs through make.com. It is written by our own server.
- Clip 8: only say Norma findings were fixed once the Norma pull request is merged. If it is not merged when you record, say "we scanned the code with Quality Clouds Norma and wrote down what we found" instead.
- Never mention a morning email, reading Google Drive live, or SLNG voice.

## How to record
- Tella or QuickTime (Command, Shift and 5, then "Record Selected Portion", microphone on). Record each clip separately. A bad clip is re-recorded alone.
- The waits to trim: first question about 6 seconds, each turn 3 to 6, the summary about 11, the review about 19, the draft about 5.
- Use "Use Elena's scripted answer" so nobody types on camera.
- Upload to YouTube as unlisted. Uploading and processing a three minute video takes 5 to 15 minutes: start the upload by 13:20 at the latest.
